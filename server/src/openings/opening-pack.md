# 做一个开场动画

Claude Web 桌面版每次（或每天第一次）打开时放一段开场。除了内置的几种（Claude Web 娘、点火、星图、字符雨、网吧开门），用户可以装「动画包」。你做的是**网页包**：一个 `index.html`，在一个沙盒框里放几秒，放完说一声，然后 Claude Web 自己接上：标志从一点火星里亮起来、字标「Claude Web · by Super NB」出来、标志飞到侧栏左上角、应用淡进来。

先调一次 `opening_guide`：它给你这份说明和一个能直接跑的范例。照着范例的结构写。

## 这个页面在哪里跑

- **一个文件**：图片、字体、声音全部写成 `data:` URI 放在页面里。没有别的文件可读。
- **没有网络**：`fetch`、XHR、WebSocket、外链的图片 / 字体 / 脚本全部被拦下。也没有 `eval` / `new Function`、没有 iframe、Worker、表单、弹窗、`localStorage`（沙盒里是空的）。
- **碰不到应用**：页面在一个沙盒框里，和 Claude Web 的界面隔开，只能用下面这一个接口说话。
- **占满窗口**：框和窗口一样大（桌面窗口，通常 1280×800 左右，也可能更大更小）。用 `innerWidth` / `innerHeight`，监听 `resize`。页面默认没有滚动条、没有边距。
- **时间**：最多放 `maxSeconds` 秒（不写就是 12，最多 12）。到点还没放完就被收掉，用户看到的会换成内置的「点火」。一般 3–8 秒最好：开场要短。
- **启动时 CPU 很忙**（服务正在起来）：动画要轻，每帧几毫秒画完。别一次画几万个粒子。
- 系统或应用开了「减少动画」时根本不放你的页面，只出标志的最后一帧——你不用管。
- 不出声：开场默认静音，别依赖声音。

## 接口：window.cwOpening

```js
cwOpening.done()   // 放完了：Claude Web 接上标志和字标。一定要调，越准越好
cwOpening.full     // true = 完整，false = 简短（用户在设置里选的）：简短时把动画压到一半左右的时间
cwOpening.dark     // 用户的界面是不是深色（标志是在黑底上亮起来的，最后一两帧淡到黑最顺）
```

`parent.postMessage({ cwOpening: 'done' }, '*')` 和 `cwOpening.done()` 一样。

## 怎么收尾

调 `done()` 之后你的页面淡掉，后面是黑底，标志的橙点在画面中间偏上（大约横向正中、竖向 36% 的地方）亮起来、炸开一圈火星。所以：

- 最后半秒把画面收到黑（或很暗），别在亮白的画面上突然切走；
- 想更连贯，把视线收到画面中间偏上那个点（一个光点、一束光、收拢的粒子），标志就从那里接着亮；
- 不要自己画 Claude Web 的标志和字标——后面会画，画两遍很怪。

## 写法

- 一个 `<canvas>` 铺满窗口，`requestAnimationFrame` 画，按经过的时间（`performance.now()`）推进，不按帧数：机器忙的时候帧会掉，时间不能跟着变慢。
- `devicePixelRatio` 最多取 2。
- 想要文字就用系统字体（`-apple-system, "Segoe UI", "Microsoft YaHei UI", sans-serif` / `Georgia, serif` / 等宽 `Consolas, monospace`），或者把字体写成 `data:` 放进 `@font-face`。
- 出错会被记下来（试放结果里能看到），但页面还是会被收掉换成点火：先保证不出错。

## 流程

1. `opening_guide` 看说明和范例。
2. 想清楚：主角是什么、几秒、怎么收到画面中间那个点、简短版怎么压缩。
3. `opening_draft` 提交（name、html，可选 author、license、maxSeconds；改同一个草稿时带上上次回给你的 id）。它会**在用户的窗口里真的放一遍**（就像打开应用时那样，盖在界面上，点一下能跳过），然后回给你：在第几秒 `done()` 的（或者到点被收掉了）、出了哪些错、每帧多少毫秒、几张画面截图（取最大的那个 canvas，1、3、6、9 秒和结束时）。
4. 看结果改：没调 `done()`、太长、太满、太慢、结尾不在中间、截图是空的。一般两三轮。
5. 用户满意了：`opening_save` 存成动画包（出现在 设置 › 外观 › 开场和背景 的卡片里），`opening_apply` 把它设成开场（会问用户）。改已有的：`opening_get` 读出来再 `opening_draft`（同一个 id）。

用户界面里叫「开场」「开场动画」「动画包」；跟用户说话别提文件名和工具名，说「我做好了第一版，刚在窗口里放了一遍，你看看」。作者写用户或者你们两个，许可问用户（不知道就写 MIT）。
