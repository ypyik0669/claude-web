## 飞出的子菜单（`sidebar/menus.tsx`）

- 全局只有一个锚定菜单（`ui/menus.ts` 的 `claimMenu`）：子菜单如果自己 claim，就会把它出来的那个菜单关掉。所以
  **子菜单是父菜单 DOM 里的孩子**，不 claim、不挂自己的 window 监听；桌面上 `position: fixed` 摆在父菜单旁边，手机上在同一张
  操作单里推进去。
- 用法：`<Menu onClose className label title anchor>` 里放 `<SubMenu id icon label value panelClass>…</SubMenu>`，子菜单
  里还能再放 `SubMenu`（显示 › 来源 ›）。`Menu` 记着打开的路径（`path`，每层一个 id，同一层同一时间只开一个），
  `useAnchoredMenu` / `MenuHost` / `ActionSheet` 的老用法一个没变，别的菜单不用动。
- 桌面：悬停 120ms 打开、离开 280ms 关（指针在面板或那一行上就不关）；点那一行也打开；键盘 → / Enter / 空格打开并聚焦第一
  行，← 关回那一行，↑↓ Home End 在面板里走；**Esc 一次只关最里面一层**（`useAnchoredMenu` 的 `onEscape`），再按才关整个
  菜单。位置是纯函数 `place.ts` 的 `placeFly`：右边放得下放右边（盖住父菜单 4px），放不下而左边放得下放左边，都放不下贴
  右边；顶和那一行对齐（-6px），太高就压到窗口里、再高就限高滚动；避开 Windows 标题栏按钮（`captionBox`）。
  `flyOrigin` 给缩放动画的原点（那一行的高度）。测试在 `place.test.ts`。
- 父菜单有子菜单开着时带 `data-fly-open`，**关掉它的 `fl-menu-in` 动画**：动画里的 `transform` 会让 fixed 的孩子以父菜单
  为包含块，子菜单就跟着父菜单缩放、位置也错。
- 关菜单时的淡出副本（`ui/ghost.ts`）不带飞出的面板（`strip: '.sb-fly'`）；面板自己关时有自己的副本——所以面板是单独的
  组件 `FlyPanel`（见「坑」）。
- 手机：`SubMenu` 点一下把页推进同一张单，左上角 ‹ 返回（`.sb-push-head .sb-push-back`，44×44），标题是那一行的字；
  每推一层 `pushBackLayer` 一次，系统返回退一层。根上的标题（`title`，比如「对话列表」）只在没推进去时显示。CSS 在
  `styles/sidebar.css`：推进去以后，根上别的行和打开那一行本身都 `display: none`，只剩面板。
- 账号菜单的 语言 › / 主题 › / 帮助与反馈 › 换成 `SubMenu`（`panelClass="acct-fly"`），阶段 1 的 `SubRow`（原地展开）
  和 `.acct-sub*` 样式删了。

## 显示菜单（`sidebar/view-menu.tsx`）

- 六行：**分组方式 ›**（文件夹 · 项目 · 日期 · 不分组）· **排序 ›**（最近更新 · 创建时间 · 名称）· **显示 ›** · 新建分区 ·
  恢复默认 · 查看全部。显示 › 里：已归档的对话、其它 Agent 的对话（勾选）、每组（5 条 / 10 条 / 全部，一个分段按钮，
  `data-per`）、**来源 ›**（全部 + 各来源和个数，最后「管理来源」→ 设置 › 对话来源，原来叫「管理对话来源…」）、
  **机器 ›**（另一台电脑有对话时才有：所有机器 · 本机 · 各台）。手机上「显示 ›」那一行右边写着开了哪几样（已归档、其它
  Agent），和方案的单子一样。
- 选了就生效、菜单不关；新建分区 / 查看全部关菜单。
- **原来菜单里的筛选框**去了两个地方：搜索（Ctrl K）和侧栏里的 **/**——焦点在侧栏（或焦点哪都不在、指针在侧栏上）按 /，
  列表顶上出一个筛选框（`.sb-slash`，`data-id="filter"`）；Esc 关，↓ / Enter 到第一行，空着失焦也关。开着菜单、对话框、
  命令面板、设置时 / 不管。手机没有键盘，抽屉顶上的搜索框就是搜索。
- **选择多个**去了 Shift + 点行，和行菜单（右键 / 手机长按）里的「选择」（`rowMenu:select`，从这一行开始选，这一行已勾上）。
- **显示按钮在哪**（`Sidebar.tsx` 的 `groupViews` / `headView`）：桌面在每个项目 / 文件夹 / 日期分组的标题上，悬停或键盘
  焦点在标题里才出来，旁边一个 ＋（在这里新建对话）；「项目」那一行只在没有分组标题可放时有（不分组、空列表、新人的文件夹
  标题写着「设为项目」时），以及**它有话要说时**（点：有筛选、显示了已归档、藏了其它 Agent 的对话）——不然这些状态在
  桌面上静止时看不出来。手机是列表标题那一个 ≡（就是「项目」那一行的按钮，图标和示意一样是漏斗），每屏一个。
- **菜单住在「项目」那一行里**（`.sb-view-host`），不住在打开它的标题里：按日期分组时项目标题没了，菜单如果在标题里就被
  卸载、关掉了。`useAnchoredMenu` / `Menu` 加了 `anchor`：摆在 `anchor()` 返回的按钮旁边；按钮不在（被换掉、被藏起来）时
  菜单停在原地。按钮用 ref 记在 `viewBtns` 里，key 是菜单的 id（`view` 或 `view:<分组>`）。打开菜单的那一组带
  `.menu-on`，标题上的按钮一直显示着。
- `entries.ts`：`VIEW` 换成十二个 id（六行 + 显示 › 里的 + 来源 › 的 library）；新加 `GROUP_HEAD`（`group-view`、
  `new-here`，PLACES 的 `groupHead`）；`ROW_MENU` 加 `select`、`kids`；`ROW` 加 `filter`（/ 的筛选框）；`LEGACY` 记了
  阶段 C 显示菜单的每一项去了哪。`palette/moved.ts` 没动：没有东西从侧栏挪去别的页。

## 分组标题

- 项目标题上原来的 ··· 去掉了，**项目菜单是标题的右键**（手机长按）；悬停只有 显示 和 ＋。
- 文件夹也有了右键菜单（`groups.tsx` 的 `FolderMenu`，`aria-label="文件夹 <名字>"`）：在这里新建对话 · 新建 worktree 对话 ·
  在这里开终端 · 设为项目 · 资源管理器 · VS Code。「设为项目」只在一个项目都没有时写在标题上（`spelled`），其余时候在菜单里。
- 手机上分组标题长按出菜单（`useLongPress`，`haptic('menu')`），标题上不放按钮（`phoneActions` 只有「设为项目」）。

## 行

- **行尾只有状态**（`rows.tsx` 的 `StatusMark`）：等你确认 / 提问是橙点（`.st.wait`，`data-kind="confirm" | "ask"`，
  字在 `title` 和 `aria-label` 里），出错红点，运行中的圈，+N −M，来源标签（别的 Agent）。**不写时间**：时间在 tooltip 的
  一行「更新于 …」。桌面 tooltip 还有一行指针 / 按键的说明，手机没有。
- 需要你：只在有人等你时出现（原来就是）；行里不再放额外的点，编排的行是图标 + 名字 + 橙点。
- **子对话缩进一层**：分叉（Claude 的分叉在 `SessionMeta.cacheKey` 里记着从哪来的；别的来源的 `parentId`）挂在根对话下面，
  不管隔了几层都挂在最上面那个根下（`filter.ts` 的 `families`，有环也不会死循环）。子对话自己也要过筛选（归档的分叉在
  不显示归档时不出现）。根被筛掉时，分叉（cacheKey）回到列表里自己的位置，别的来源的子对话（parentId）跟着根不显示（它们
  从来不单独成行）；置顶的分叉留在置顶里。子对话超过 3 个（`KIDS_SHOWN`）默认收起，收起时当前打开的 / 在跑的照样显示；收放记在
  `layout.sidebar.sections` 的 `kids:<id>`（和分组一样）。桌面在行前面一个小箭头（展开着时悬停才显示，收起时一直在），手机和右键菜单里是
  「收起子对话 / 展开 N 个子对话」。
- **服务端**：`LibraryService` 原来把子对话折掉不发（只在根上记 `childCount`），前端根本拿不到。现在 `list()` 时把折掉的
  孩子记下来（`parentId` 换成别名解析后的根），`children(roots)` 按根筛、新的在前；`sessions.list` 把它们跟在列表后面一起
  发（bot 对话照样排除）。联邦的 `prefixSummary` 本来就给 `parentId` 加前缀，不用改。
- 旁聊（`side_question`）不产生对话，所以没有「旁聊」行可缩进；缩进的只有分叉和别的来源的子对话。
- 手机：行尾没有 ⋯，长按出行菜单；行菜单在手机上去掉「在新标签打开 / 在右侧打开」（手机一次只显示一个对话）。

## 搜索找得到 Artifacts（`palette/artifacts.ts`）

- 命令面板打开时读一次 `artifacts.list`（60 秒缓存，同时只发一个请求），按文件名（最先）、来自哪个对话、目录最后两段匹配，
  最多 8 条，排在对话后面（`>` 只搜命令、`agent:` / `in:` 筛对话时不出）。点了在文档标签页打开。
- 输入框提示：桌面「输入命令，或搜索对话和 Artifacts…  > 只搜命令 · agent:codex · in:目录」，手机「搜索对话、Artifacts 和
  命令」，手机不显示底下的按键说明和每条后面的快捷键。抽屉的搜索框写「搜索对话和 Artifacts」。

## 坑

- **`useLeaveGhost` 不能挂在条件渲染的孩子上**：它在 deps 变化时不做副本，面板开着关着在同一个组件里切换，被当成 deps
  变化，关面板时一直没有淡出副本。面板拆成自己的组件 `FlyPanel`，关 = 卸载，副本照常。
- **菜单挂在会被重建的标题里会被一起卸载**：分组方式从「项目」换成「日期」时项目标题整个换掉，菜单跟着没了。见上面
  「菜单住在项目那一行里」。验证：桌面打开项目标题上的显示 → 分组方式 → 日期 / 不分组 / 文件夹 / 项目，菜单和飞出的面板
  一直开着。
- 子对话一直没显示过：不是前端的事，服务端折掉了（见「服务端」）。Claude 自己的分叉没有 `parentId`，要看
  `cacheKey`（「从 Mirasim 借鉴的功能」里的分叉）。
- ui-smoke 里打开显示菜单别直接点 `.sidebar [data-id="view"]`：有项目以后那一行没有这个按钮（用 `viewBtn()`）。i18n-smoke
  的 `click` 是 `element.click()`，不用先悬停。
- 子菜单开着时按两次 Esc 不一定关得掉整个菜单（一次一层）：收尾用的 `closeMenus` 在 i18n-smoke 里多按一次。

## 和方案不一样的地方

- 「项目」那一行的显示按钮：方案只说项目标题悬停出显示；这里在没有标题可放、或者有筛选 / 已归档 / 藏了其它 Agent 时，「项目」
  那一行也有一个（带点），不然这些状态静止时看不到、也没地方打开菜单。
- 每组是显示 › 里的一个分段按钮，不是再一层子菜单（三个选项，一眼看完，少点一下）。
- 文件夹标题没有 ··· 按钮（方案图里也没有），文件夹菜单走右键 / 长按；「设为项目」从标题上的钉子挪进菜单（没有项目时还写在
  标题上）。
- 手机行菜单去掉了「在新标签打开 / 在右侧打开」（方案没提，手机上点了看不到结果）。
- 旁聊不缩进（它不产生对话）。
- 机器 › 只在别的电脑有对话时出现（阶段 C 就是这样）。
