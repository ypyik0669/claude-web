- `EMPTY.filesSession`：「本对话的文件」组（Claude 读过 / 改过的文件，`touched-files.ts`，只看顶层工具调用）没有时，两个按钮：
  「打开文件」（桌面版原生选择框；网页版没有，转去搜索）和「搜索文件」带键（网页版 Alt+P；桌面版 **Ctrl+Shift+F**——
  桌面菜单的 Ctrl+P 早就是「搜索对话」，没抢）。快捷键 id `files.search`，发 explorer 的 search 意图。
- `EMPTY.filesNoFolder`：对话没有目录时，「打开一个文件夹」选的目录只在这个面板里看，不写进对话。
- EmptyState 现在允许一到两个按钮。
