- **设置表是纯数据**：`web/src/features/settings/catalog.ts`（`SETTINGS_GROUPS` 常用 / 模型 / 扩展 / 连接 / 数据 / 高级，`SETTINGS_SECTIONS` 每页 `group`、`advanced`、一句 `desc`、`entries`（行：`EntryId`，带 `block` 分节标题、`more`、`tag`）、`bodies`（页面部分：`BodyId`）、`more`（收进「更多选项」的部分）、`tabs`（现在只有 MCP + 插件一页有两个 tab；「其它 Agent + 子代理」那页随「只留 Claude」变成只有子代理）；`BODY_INFO` 是每个部分的名字和搜索词）。`SettingsModal.tsx` 只负责渲染：`CONTROLS: Record<EntryId, …>`、`BODIES: Record<BodyId, …>`，**少一个渲染器编译不过**。加一项设置 = catalog 里加一行 + 一个控件；加一个部分 = `BodyId` + `BODY_INFO` + `BODIES`。
- **可见一级分区 14 个**（3 + 2 + 4 + 3 + 2；2026-11-01 模型组去掉了「模型网关」，连接组后来加了「联网」），高级 6 个（Hooks / 环境变量 / CLI 工具 / 诊断 / 更新 / settings.json）默认折叠成一行灰字，当前页在高级里时自动展开。左栏行尾状态（`navStatus()`）只用便宜的数据：`config.auth`（服务端 30 s 共享）→ 已登录 / 未登录、供应商个数（以前还有 `gateway.status` → 开 / 关，网关已删）；**不显示 MCP 个数**（`claude mcp list` 会拉起所有 MCP server，打开设置不该触发它）。左下角是版本（桌面版 `desktop.version` + 更新状态，点它去「更新」）。
- **旧 id 全部可用**：`LEGACY_SECTIONS`（`interface` / `session` → `general`、`engine` → `account` 并展开「更多选项」滚到运行内核（`{more: true, body: 'engine'}`）、`plugins` → `mcp` 的「插件」tab、`subagents` → `agents`），其它旧 id 就是新页面 id。`resolveSettingsTarget({section, reveal})` 是唯一解析入口（`reveal` 优先，条目在「更多选项」里就展开它；未知 id → 通用）。`catalog.test.ts` 把旧设置窗的 22 个分区原样写成契约：旧的每个 entry id 都在且只出现一次、每个旧部分都在某一页、每个旧 id 打开的页面（和 tab）包含它原来的内容，并区分「打开就看得见」和「收在更多选项里」（`BEHIND_MORE` 表逐项列出，其余必须直接可见；环境变量是唯一搬家的，断言它在「高级 → 环境变量」）、可见 ≤ 15、分组和 spec 表一致、`WORKBENCH_SETTING_PATH` 与「显示工作台工具」所在页一致。
- **每页常用在上、低频收进「更多选项」**：通用（软件渲染 / 编排并发上限）、外观（中文字体）、账号与登录（运行内核：`Overview part="engine"`，官方 Claude Code 的版本和来源 / doctor）、MCP（手动添加 JSON：`McpAddJson`）、Skills（备份：`SkillsBackup`）、手机与其它电脑（SSH 隧道：`HostsSection`）。「更多选项」第一次展开才挂载（里面的请求等到那时才发），之后收起只是 `hidden`。为此拆开的组件：`ConfigPanel` 的 `Mcp` / `McpAddJson`（增删后 `mcpChanged()` 发 `cw:mcp-changed` 窗口事件，列表和目录的「已装」都重载）、`Overview({part})`、`EnvEditor` 搬到 `features/settings/EnvEditor.tsx`（`bare` 去掉自带标题，页面标题已经说了）、`AccountSection`（登录状态在最上，走 `config.auth`）、`RemoteSection` 不再内嵌 `PeersSection` / `HostsSection`。停靠面板的配置中心照旧组合这些部分（MCP tab = 列表 + JSON 表单）。
- **全窗布局**：根元素仍是 `.modal.settings`（各页组件是按 `.modal input / select / label` 调过的，`.gw-* select {width:auto !important}` 之类的规则就是跟它打架留下的），再加 `.sp`：`position:fixed; inset:0; z-index:50`（命令面板 55、toast 60、对话框 200 都在它上面），应用本身不卸载。样式全在 `styles.css` 末尾「redesign phase 6: settings」块：`sp-nav`（260px，≤ 900px 时 220px）、`sp-inner`（660px 居中）、`sp-card` / `sp-row`（标题 + 一句后果 + 右侧控件）、`sp-seg`（两三个选项的分段控件：改动的显示方式）、各页旧组件的 `.section h5` / `.list` / `.kv` 在页面里自动变成「分节标题 + 卡片」；`select.field` 在页面里 `width:auto`（否则 `.modal select {width:100%}` 会把同一行的搜索框挤成 0 宽）。≤ 600px（手机）导航和页面轮流显示（`.phone-page`，页面顶部「全部设置」回到导航；搜索时（`.searching`）搜索框留在顶上、结果占下面）；手机侧栏抽屉（fixed、z-index 60，在设置页之上）打开时收起、开着期间也保持收起（订阅 store，Ctrl+B 不会把它拉到页面上面）；命令面板 / 快捷键表打开时同样收起它（终审 M4：`ui/viewport.ts` 的 `drawerYields(prev, next)`，`App` 订阅 store）。桌面版：导航顶行和内容区顶上 40px 的 `.sp-drag` 是标题栏拖动区，mac 顶行左让 76px。
- **焦点 / 键盘**：设置页盖住整个窗口但应用不卸载，所以**必须把键盘拿走**（审查 C1：不然 Ctrl+, 之后继续打的字进了被盖住的 composer，Enter 会发出去，Esc 会中断运行中的对话）。`features/settings/cover.ts` 的 `coverApp()`：挂载时（`useLayoutEffect`）记下 `document.activeElement`，先 `closeAnchoredMenus()`（`ui/menus.ts` 的 `cw:close-menus` 窗口事件：每个锚定菜单开着时都订阅它（`useMenuClaim` / `claimMenu`，同一个事件也保证全局只开一个菜单，见「界面改版 阶段 4」），portal 到 body 的菜单不在 inert 范围里，留着会浮在设置页上还能点；新加的锚定菜单也要用 `useMenuClaim`（开关状态在父组件里的下拉用 `useDropdown`）），再给 `.app` 下除设置页以外的兄弟节点加 `inert`（不卸载；豁免是**白名单** `ABOVE_COVER`：对话框、命令面板、快捷键表（`.shortcuts-bg`，z 52，终审 M1：设置页上按 `?` 它在上面，Esc 只关它、焦点还回设置页）、toast、图片查看器、错误边界浮层、首次引导——不按 z-index 判断，手机抽屉也是 fixed z 60；打开期间新插进来的兄弟节点由 MutationObserver 补上），桌面聚焦搜索框、手机（`store.mobile`）聚焦根元素（`tabIndex=-1`，免得弹出软键盘）；关闭时只去掉自己加的 `inert`，原元素还在 DOM 里就把焦点还回去。Esc：搜索框里有字就只清空搜索，否则关闭——焦点在页面里时由根元素的 `onKeyDown` 处理（页面里的控件先处理、可以拦），焦点落在 `<body>`（对话框关掉后、点过 toast、聚焦的结果行被卸载）时由挂载期间的 window 捕获阶段监听处理，赶在 `App` 的全局 Esc（它会直接关设置）之前；焦点在对话框 / 命令面板里时归它们（命令面板的 Esc `stopPropagation`，只关面板）。`/` 聚焦搜索（不在输入框里时）。**设置页开着时的快捷键**（终审 I2，和自动化页对称，纯函数 `workbench/cover-commands.ts` 的 `underCovers(id, {settings, automation})`，`runCommand` 开头调它，浏览器按键和桌面菜单加速器都经过这里）：`tile.close`（Alt+W / Ctrl+W）只关最上面那一页（设置页先于自动化页），不关下面看不见的标签；`new / tile.* / pane.* / group.* / tab / interrupt / close / window.new` 先关掉盖着的页再执行；`palette / settings / sidebar / dock.* / panel.*` 照旧。**主区域被换内容时设置页也关**（复审 M-5，`settings/close-on-nav.ts` 的 `installSettingsClose()`，App 里装一次）：和自动化页同一个判断（`onLayoutAction` + `closesAutomation`）——在设置页上的命令面板里选一个对话、设置里的按钮开了终端标签，设置页关掉、看得到结果（以前在设置页下面打开，什么变化都看不到）；晚到的答复（`meta.since` 早于设置页打开的时间）不关。设置页开着时再 `openSettings()`（不带 section / reveal，比如再按一次 Ctrl+,）只清空搜索并聚焦，不换页；换页时左栏把当前项滚进视野。桌面标题栏按钮的底色在设置页打开时一律 `--bg`（`App.tsx` 的 `sideSurface` 看 `settingsOpen`）。搜索覆盖每一行（label / hint / keywords / id / 分节标题）和每个页面、tab、部分（`BODY_INFO`），「高级」和「更多选项」里的也搜得到；多个词必须都命中；行直接在结果里可改（带「分组 › 分区」面包屑，点面包屑打开那一页并高亮这一行），页面 / 部分是跳转行，跳到「更多选项」里的部分会展开并滚过去（`data-body`）。
