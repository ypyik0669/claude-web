## 运行中 = 在跑（列表 / 网吧）+ 跑过的

- 页还是后台页（`features/background/BackgroundPage.tsx`，`OverPage name="bg"`），右上角「在跑 / 跑过的」照旧。在跑下面两种看法：
  **列表**（`RunList.tsx`，纯逻辑 `run-list.ts` + `run-list.test.ts`）和 **网吧**（`office/Office.tsx`），看的是同一份快照。
- **列表按对话跑的东西分组**（照示意图的卡片）：一个工作流（下面是它的子代理行）、一个单独的子代理（一行）、一条后台命令（没有行）
  各一组；同一个对话的组挨在一起——有在跑的对话在前、最新变化在前（`sortSessions`，和网吧的区一个顺序），对话里在跑的在前、最新开始的
  在前（`orderedTasks`）。组头：图标 · 名字 · 「acme-shop · 工作流 · 8 分钟」（`groupMeta`）· 在跑的工作流的阶段「改代码 2/4」
  （`phaseChip`：第一个在干活的子代理所在的阶段，没有就第一个排队的）· 停止（在跑才有）· 打开对话（提示里是对话名）。
  子代理行：点 · 名字（工作流里的 label，单独子代理写类型）· 在做什么 / 怎么结束的（`agentLine`）· tokens；点一行在旁边开它自己的
  对话（`AgentDrawer`）。超过 8 个折成「还有 N 个」，在干活的先露出来（`shownAgents`）。
- 工作流组下面「关系图和动态」（桌面，默认收着）：原来那张节点图（`CommandGraph`，只画这个工作流）+ 它的动态（`EventFeed`）。
  卡片（`AgentCards`）和任务 chip 删了：列表的行就是它们的简版，人物在网吧里。
- 跑完一分钟内的任务还在快照里（「后台」的 `pruneEnded`）：组头写「完成 / 失败 / 已停止」，没有停止。
- 标签下面那行（`liveSummary`）：「3 个在跑 · 2 个对话 · 3 个子代理在干活 · 90.0k tok」；跑过的那行照旧。页标题一律「自动化」（以前运行中
  把标题改成正文字体，因为那时标题是对话名；现在和其它四个标签一样）。
- **进页面时带着对话**（输入框上方的胶囊、对话里工作流卡片的「在「后台」里看」、任务面板）：列表把那个对话的组滚进来、描一圈
  1.6 秒（`useBackground.focusAt`）；带着工作流的在桌面上顺便展开它的关系图。快照晚到时等组出现了再滚。

## 列表 / 网吧

- 桌面：家族标签行右端一个分段（`RunViewSwitch`，`.bg-runview`）。`OverPage` 多了 `tabsEnd`，家族的标签行外面多包一层 `.fam-line`
  （所有家族页都包，标签行不会因为有没有分段而重新挂载）。选择存 meta.json 的 `background.view`（`run-list.ts` 的 `RUN_VIEW_KEY`，
  `setRunView` 走 `setSetting`），默认列表。
- 手机：头部 ⋯（`PhoneMore`，用 `sidebar/menus` 的 `Menu`，手机上是底部操作单）：「列表 / 3D 网吧」，网吧显示时下面是网吧的工具。
  **只管这一次**（`useBackground.phoneCafe`，`closeBackground` 清掉）：方案要手机默认列表、省电；存进 meta.json 的话桌面选了网吧，
  手机也会开网吧（同一份 meta.json）。
- 回放（跑过的 › 在网吧里回放、刚跑完的 › 回放）播着时一律显示网吧（`useRunView` 看 `useReplay` 的 `where === 'cafe'`），不动记住的
  选择；结束回放回到原来的看法；回放时点「列表」会结束回放。
- 网吧第一次显示才挂载（three.js 自己的 chunk，只看列表的人不下载它），之后只 `hidden`；`hidden` 时 IntersectionObserver 让场景不画。
  网吧撑满页面主体（`.bg-body.cafe`），不再是 72vh 加下面一块板子。
- 子代理的对话（`LiveDrawer`）在列表 / 网吧旁边：`.bg-body` 横排，列表或网吧让出位置（≤ 1100px 浮在右边，手机从下面拉起）。

## 跑过的的尾巴

- **页自己的左栏去掉了**（`BackgroundSide.tsx` 删除，`registerPageFrame('bg', FRAME)` 不再带 `Side`）：列表已经把所有对话按对话分组列出来，
  网吧有自己的「各区」，跑过的有自己的列表；左栏在跑过的下面还列着在跑的对话。跑过的现在占满宽度。左栏里「这个对话跑过的工作流」
  去跑过的看（能按对话名搜）；从它点开的「某次跑完的运行」（`runId`、`useRun`、「回到现在」、`model.ts` 的 `reopenRun`）一并删了。
  服务端的 `background.history`（按对话列运行）还在，phase 25 在用。`frame.ts` 的 `Side` 机制留着，现在没有页用。
- **空网吧那句话**：卡片 `width: max-content`（放得下就一行）+ `text-wrap: balance`（放不下就两行一样长），不会再把「里。」甩到第二行。
  列表空着时是同一句（`EmptyState`，balance）+ 刚跑完的三条。
- **360px 手机的头部**：☰ · 自动化 · 在跑 / 跑过的 · ⋯ · ×。「停止 / 全部停止 / 回到对话 / 回到现在」从头部去掉了——停止和打开对话
  在每一组上（网吧里人和区的卡片上也有）；手机上「在跑」后面不写数字（下面的「运行中 3」标签写了，360 也放不下）。每个都是 44。

## 手机上的网吧（问题 14）

- `Office` 认 `phone`（`store.mobile && !compact`，根上 `.office.phone`）：不画底栏（面包屑 / 提示 / 缩放）和右上角的工具（白天夜里 /
  角色库），这些都在页头 ⋯ 里——跟着主题 / 白天 / 夜里、放大、缩小、整个网吧、角色库（`OfficeControls`：页拿 `controls` ref 调
  `zoom` / `whole`，白天夜里本来就是设置 `office.light`）。计数胶囊独占顶上，不再被「白天 / 夜里」盖住；画布从标签下面到屏幕底，
  没有圆角和留白。
- 人头上的按钮在手机上 `pointer-events: none` + `aria-hidden` + `tabIndex -1`：人坐得比手指窄，44 的点按区会互相压住。点人走画布
  自己的 `pick`（射线），区的卡片里也逐行列着人（行 44）。区牌在手机上 44 高——`placeTags` 按元素的实际高度把它们错开，所以不会叠。
  卡片里的按钮和行都是 44。没有 WebGL 的列表版（`.office-flat`）人是行，照常能点（规则只写在 `.office-anchors` 下面）。

## 坑

- `.over-body` 是 `flex-direction: column`（styles.css）：`.bg-body` 改横排要写明 `row`，不然列表按内容宽度缩成一条（桌面），手机上撑出屏幕。
- 空网吧的卡片在 `compact` / 手机上是 `left` + `right` 撑开的，加了 `width: max-content` 以后要改回 `width: auto`（三个都写时 `right` 不算）。
- A3（网吧的滚轮）以前靠「网吧在会滚的页里」：滚轮只缩放、页面不动，外面滚一下做对照。网吧撑满以后外面没东西可滚，改成：滚轮被网吧
  拿走（prevented）而且缩放真的变了、Shift + 滚轮不拿。往哪边是放大先用一下滚轮探出来（往里缩，适配后的视图离下限只有一两格）。
- 「已处理过的 focus」用 `useRef(focusAt)` 当初值的话，胶囊第一次打开页面（RunList 这时才挂载）就被当成处理过了：初值 `undefined`，
  找到组之后才记。描一圈的定时器单独一个 effect，不然 groups 每秒变一次会把它清掉、那一圈一直在。
- 跑过的的搜索框：label 有 44 高，里面的 input 只有 26，体检按 input 量——input 要撑满（`align-self: stretch`）。
- **ui-smoke 往 store 里塞的定时任务会被冲掉**：除了草稿，每次 `settings.set` 服务端都广播 `meta.changed`，前端 `loadMeta()` 把服务端自己的
  定时任务列表拿回来。手机体检先 `setSetting('background.view')`、每个主题又 `setSetting('ui.theme')`，循环外塞一次的列表到定时任务标签时
  已经没了（第一遍全量 ui-smoke 就挂在这，6 个尺寸 × 4 条）。改成到了定时任务标签再塞，行没出来就再塞（最多三次）。后台快照不受影响：
  只有重连的 `hello` 才重取它。
- `scripts/i18n/extract.mjs` 第一个参数不是 `--check` 就当输出目录：`--help` 会在仓库根建一个叫 `--help` 的目录。

## 和方案不一样的地方

- 列表的组 = 对话跑的每一样东西（示意图的卡片就是这样），同一个对话的挨在一起，没有单独的「对话」标题行；对话名在「打开对话」的提示里。
- 每个在跑的组都有「停止」（示意图只给后台命令画了）：头部的停止去掉以后，不然停不了工作流和子代理。
- 手机上组头第二行照手机示意：阶段代替时长（「acme-shop · 工作流 · 改代码 2/4」，桌面是名字旁边的小 chip），子代理不写种类
  （「acme-shop · 子代理 · 3 分钟」，种类在它那一行上，`groupMeta` 的 `short`）。360 宽放不下时折成两行，只在「 · 」后面断
  （`RunList` 的 `keepParts` 把段里的空格换成不断行空格，CSS `word-break: keep-all`），不会把「20 分钟」「改代码 2/4」拆开。
- 手机上网吧的选择只管这一次，桌面记在 meta.json（理由见上）。
- 手机上「在跑」不带数字。
- 「列表」的图标用 `menu`（≡）：图标表里没有 lucide 的 list，加图标要重新生成 `icons.generated.ts`，几个分支一起改容易撞。
- 手机上的网吧没有双指缩放，缩放在 ⋯ 里（点一下关一次单子）。
