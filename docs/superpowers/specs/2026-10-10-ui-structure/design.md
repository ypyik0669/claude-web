# 界面第二轮：图标栏 + 分区页；联网（搜索 / 浏览器 / 操控电脑 / 扩展目录）

2026-10-10。上一轮（`../2026-10-10-ui-refresh/design.md`）换的是外观：颜色、卡片外壳、字体、图标、动效、手机。
入口在哪、每个页面怎么排没有动。用户看了 Codex 桌面应用之后的反馈（附 7 张截图）：

> 很多按键…完全位置也不对，也很丑，也不符合逻辑，不人性化，也不美观…每一个按钮，包括什么深度编排什么的…
> 还有就是我想在 claude web 里也做一个内置网络搜索的功能，就是能打开内置 browser，能用 computer use，能接各种东西。

用户定的：**图标栏 + 分区页**（Codex 那种）；不先打安装包，做完一起装；测试留下的临时目录全部做完后删。

## 1. 现在哪里不对（对着分支上的截图看的）

| 哪里 | 问题 |
| --- | --- |
| 工作台工具 | 分组栏 + 标签条 + 会话头三行外框；分组栏右边一排 11 个没有字的图标 |
| 模型菜单 | 智能程度分段、深度编排开关（两行说明 + 小开关）、几十个模型、三个底部链接挤在一个弹层 |
| 自动化 | 一列一样的时钟图标 +「使用」按钮；空状态是一行灰字 |
| MCP / Skills / 插件 | 在设置里；卡片上直接写 `stdio · npx -y …`，没有图标 |
| 浏览器 | 只是窗格里的一种标签，agent 用不了 |
| 搜索 | 引擎默认 Tavily（要 key）：走中转 / 别家模型的对话搜不了 |

## 2. 结构

```
+----+-------------+---------------------------+----------------+
| 栏 | 分区的侧栏   | 分区的页面                 | 右侧面板        |
+----+-------------+---------------------------+----------------+
```

### 2.1 图标栏（`features/rail/`，只在桌面宽度）

宽 52px，坐在外壳底色上，最左。从上到下：

- 侧栏开关（收起时也在：以前的「展开侧栏」）
- **对话** · **自动化** · **扩展**：三个分区。当前分区是实心底的圆角方块。
- **···**（更多）：总览 · 用量与账本 · 共享记忆 · Issue 与 PR · Android · 配置中心。每一行右边一个图钉：钉住的直接出现在
  图标栏上（`ui.railPins`，meta.json）。点了是右侧面板里的临时标签（和以前一样），不是分区。
- 底部：设置（齿轮）· 账户（头像外面一圈额度环；点了是原来账户行的弹层）。

手机（≤ 760px）没有图标栏：侧栏抽屉里保留「新对话 · 搜索 · 自动化 · 扩展」几行和底部的账户行。

### 2.2 分区

`features/sections/state.ts` 的 `useSection`：`'chat' | 'automation' | 'extensions'`。自动化、扩展仍然是盖在窗格层上的一层
（`.main-stack`，第一次打开后常驻、之后只 `hidden`；窗格和终端不卸载），「去别处就关」「Esc 关」「盖着时快捷键怎么走」沿用
自动化页已有的规则，两个页共用。分区不是 `chat` 时**侧栏那一列换成这个分区自己的内容**：

- 对话：现在的对话列表。顶上是品牌 + 搜索图标（Ctrl K），下面一行「新对话」。「自动化」那一行、底部账户行在桌面上没有了
  （在图标栏）。
- 自动化：标题 · 新建 · 「定时任务 / 目标 / 编排」三行（带数量）· 当前那一项下面是它的条目。页面里不再有自己的 tab。
- 扩展：标题 · 「连接器 / Skills / 插件」三行 · 已装的列表。

### 2.3 工作台工具

分组栏右边那一排面板图标取消（面板从图标栏的 ··· 和右侧面板的「更多」打开）。「显示工作台工具」只剩「分组栏、标签条一直
显示」。

## 3. 控件

- **输入框**：`+ · 项目 · 分支 ｜ 模型 · 强度 · 权限 · 麦克风 · 发送`。模型和强度是两个钮。
  - 模型菜单只管选模型：搜索 · 平铺列表 · 底部一行「管理…」。
  - 强度菜单：每档一行（名字 + 一句话），当前的打勾；最下面一行 **深度编排**（单独的图标和一句话，开着时钮上写「深度编排」）。
    没有档位的 agent 不出这个钮。
- 其余的逐个过：位置、图标、字、悬停 / 按下 / 焦点、tooltip。清单和结论记在本文 §7。

## 4. 页面

- **自动化**：没有任务时是「大图标 + 标题 + 一句话 + 两列模板卡片」；每个模板有自己的图标和颜色。有任务时列表在上、模板在下。
- **扩展**：目录。每项 = 图标 + 名字 + 一句话 + 一个「添加」；命令行 / 地址收进详情。已装的在侧栏。设置里的 MCP / Skills
  页照旧（旧 id 都能用），两边是同一批组件。
- **浏览器**（右侧面板第五个固定标签）：标签条 · 地址栏 · 网页。新标签页：工具（终端 · 审阅 · 文件）+ 最近打开的网站。
  agent 打开的标签带「对话名」的小标记。固定标签放不下时，只有当前那个带字，其它只剩图标。

## 5. 联网

### 5.1 搜索（`server/src/web/`）

不用 key：Bing、DuckDuckGo 的 HTML 结果页（走本服务的网络代理）。有 key 的（Tavily、Brave）在设置里选。
`web.search.engine` = `auto`（Bing → DuckDuckGo）| `bing` | `duckduckgo` | `tavily` | `brave`。

### 5.2 给 agent 的工具（MCP，名字 `web`）

和共享记忆一样三条注入路径，不改用户自己的配置。总开关 `web.mcp`（默认开）。

| 工具 | 做什么 |
| --- | --- |
| `web_search` | 搜索，返回标题 / 地址 / 摘要 |
| `browser_open` | 打开网址，返回标题 + 正文（截断）+ 可点的元素 |
| `browser_read` | 再读当前页（翻页用 offset） |
| `browser_find` | 在当前页找元素 |
| `browser_click` / `browser_type` / `browser_press_key` / `browser_scroll` / `browser_back` | 操作 |
| `browser_screenshot` | 截图 |

MCP 进程（stdio）→ `POST /api/web/tool`（只认回环 + 本次启动的随机令牌）→ `WebService`：

- 搜索在服务端做。
- 浏览器操作交给**一个**连着的桌面窗口（它先发过 `browser.host {on:true}`）：事件 `browser.command {id, sessionId, op, args}`
  只发给它，它在右侧面板的浏览器里做，用请求 `browser.result {id, ok, answer | error}` 回。30 秒没回算失败。
- 没有桌面窗口（网页版、手机）：`open` / `read` / `find` 退回服务端抓取（HTML → 文字），其它操作回一句「需要桌面版」。

### 5.3 安全

- 网页内容是数据，不是指令：工具结果开头写明来源地址，正文放在标记里。
- `web_search` 默认放行；其余跟对话的权限模式走（每步询问时逐次问）。
- agent 的标签和用户自己的标签共用一个浏览器分区（登录状态共用）——设置里写明；`web.browser.isolated` 打开后 agent 用单独的分区。
- `/api/web/tool` 远程监听器 404。

### 5.4 操控电脑

`+` 里已有开关（引擎的 `--computer-use-mcp`）。引擎里有 Windows 的输入 / 截图实现，但在 headless 驱动下通不通没验过：
实测，通就留着并在开关上写清楚要什么；不通就把开关在 Windows 上标成「暂不可用」并写原因。

## 6. 阶段

1. 图标栏 + 分区框架 + 侧栏三种内容（界面冒烟跟着改）。
2. 输入框：模型 / 强度拆开；其余控件逐个过。
3. 自动化页、扩展页。
4. 联网：服务端（搜索、MCP、协议）→ 浏览器面板和 host → 设置 → e2e。
5. 操控电脑实测。
6. 全量验证：typecheck、单测、build、ui-smoke、e2e；更新 CLAUDE.md / CHANGELOG。

## 7. 实施记录

### 做了什么

**图标栏和分区**（阶段 1）。桌面上窗口最左边是 52px 的图标栏（`features/rail/`）：收起侧栏 · 对话 · 自动化 · 扩展 · ···，
底下是设置和账户头像（头像外面一圈是额度）。侧栏那一列跟着分区换内容（`App` 的 `SidebarColumn`：每个分区一个
`.sb-sect`，第一次看到才挂载，之后只 `hidden`）。自动化、扩展是盖在主区域上的页（`features/sections/`：`OverPage`
外壳、`SectionSide` 分区侧栏、`pages.ts` 登记表——同一时间只开一页）。「显示工作台工具」下那排没有文字的面板图标
（`DockRail`）删了：这些面板在 ··· 里，每行有名字和一句话，可以钉到图标栏上（最多 4 个，meta.json `ui.railPins`）。
手机没有图标栏，侧栏抽屉里多一行「扩展」，页面自己带 tab 和关闭。

**输入框**（阶段 2）。模型和「想多深」拆成两个按钮：模型菜单只选模型；旁边的强度按钮（`models/EffortChip.tsx`）一行一个
档位、带一句说明，「深度编排」是最后一行的开关，开着时按钮变成强调色。

**页面**（阶段 3）。自动化 → 定时任务没有任务时是「图标 + 标题 + 一句话 + 新建」，下面是带图标和颜色的模板卡
（`automation/templates.ts`）。扩展页（`features/extensions/`，第一次打开才加载）：连接器目录（服务自己的标志，
`ui/brand-icons.generated.ts`，来自 simple-icons）、Skills、插件——和设置里那几页发同样的请求，画法是「标志 + 名字 +
一句话 + 一个动作」。窄页的内容列在卡片里居中，标题行和它同宽。

**联网**（阶段 4）。服务端 `server/src/web/`（搜索、`web` MCP 服务器、`/api/web/tool`、`browser.*` 协议）。客户端
`web/src/features/browser/`：右侧面板第五个固定标签「浏览器」（`BrowserPanel`：地址栏、网页、两个以上才出现的标签条、
新标签页）；`host.ts` 把这个桌面窗口登记成 Agent 的浏览器，逐条执行 `browser.command`；`ops.ts`（一次操作的顺序：
做 → 等页面停下 → 读回来）、`guest.ts`（用 `<webview>` 实现）、`page-agent.js`（注入网页里的脚本：正文、可操作的元素、
点击、输入、滚动）。设置 → 连接 → 联网。对话里 `mcp__web__*` 的步骤和审批卡有自己的文字（`web-tools.ts`）。

**操控电脑**（阶段 5）。实测结论：从这里开的对话带上 `--computer-use-mcp` 会在第一条消息之前退出（exit 1）——那个参数
只是引擎自己「作为 MCP 服务器运行」的入口，引擎只在它自己的终端界面里装配 computer use（`main.tsx` 里
`!getIsNonInteractiveSession()`）。所以这个开关以前不是「没效果」，而是「一开对话就起不来」。现在不再传这个参数；`+`
里那一行标成「暂不可用」并写明原因和替代（上网用浏览器）。真要支持，需要改引擎（无界面模式下装配它，并把
`request_access` 的批准接到权限卡）再发一个引擎版本——没做，留给用户决定。

### 和设计不一样的地方

- **固定标签的短形式**：五个名字在默认 440px 的面板里、Windows 的 − □ × 旁边放不下，所以固定标签有短形式——只有
  前面那个带名字，其它是图标（名字在 tooltip）。按最宽的名字算宽度，切标签不会让整行移动；连短形式都放不下才把整行挪到
  系统按钮下面（`tab-row.ts` 的 `fixedShort` / `shortFixedWidth`）。浏览器里（没有系统按钮）440px 放得下五个名字。
- **新标签页**没有「工具（终端 · 审阅 · 文件）」：它们就是同一行的固定标签，再列一遍是重复。只有搜索框和最近打开。
- **元素编号**不是 `e12`，是每个页面三个随机字母加序号（`kqz12`）：第一次真跑时，Agent 拿上一页的 `e1` 点到了下一页的
  另一个元素（浏览器冒烟抓到的）。
- **Agent 的操作不抢用户的标签**：浏览器在别的标签后面时，网页仍按原尺寸排版、只是不显示（`visibility: hidden`），
  读、点、输入照常；只有三种情况把浏览器带到前面——这个对话第一次打开网页、右侧面板整个收起了、要截图（没画出来的
  页面截不了，`capturePage` 会一直等：桌面壳那边等 5 秒就放弃）。
- **`note` 里不放网页上的字**：服务端把 `note` 显示在「不可信内容」标记外面，所以它只说自己的话（「已点击 [kqz3]」），
  不带元素名字、不带地址。
- 设置里的「联网」是第 15 个可见分区（上限 15）。
- **临时标签要么整个显示、要么收进「更多」**：五个固定标签之后，默认宽度的面板里临时标签条只剩 70 来像素，「配置中心」
  被左边的渐隐切成了半个字。现在按名字估出最宽那个临时标签要多宽（`tempTabWidth`），放不下一个整的就收起
  （「更多」上一个数字，面板顶上一行名字和 ×）。
- `+` 里的「控制浏览器」改叫「控制 Chrome」：它是用户自己的 Chrome（要装 Claude 扩展），内置浏览器不用开关，
  两个都叫浏览器会分不清。
- 网页版的 iframe：会和应用同源的文档（应用自己的地址、`about:blank`）不带 `allow-same-origin`（`frameSandbox`）。

### 验证

- 单测：web 1466、server 1231（+2 跳过）、desktop 19；`npm run typecheck`。
- `node server/ws-phase23.mjs`：46 项（真 server + 真 MCP 进程，假搜索引擎、假窗口）。
- `node scripts/browser-smoke.cjs`（新）：45 项——真 Electron、真 `<webview>`、本机一个小网站：用户自己浏览；Agent 的
  打开 / 读 / 找 / 输入 / 选下拉 / 点击 / 按键 / 提交表单 / 返回 / 滚动加载 / 截图；标签在后面和面板收起时；以及
  MCP 进程 → server → 窗口 → 网页 → 结果 的整条链路。
- `node scripts/ui-smoke.cjs`：347 项，其中新加的是图标栏、··· 和钉住、扩展页、强度按钮、浏览器标签（网页版）、操控电脑那一行、
  临时标签收进「更多」。
- `npm run e2e`：17 个 phase 全过。

### 没验的

- **真模型没跑过**：搜索和浏览器工具的整条链路是用 MCP 协议直接驱动验证的，没有让一个真的模型自己决定去搜、去点
  （不花用户的额度）。`WEB_SEARCH_ADAPTER`（供应商对话里引擎自带的 WebSearch 改用 Bing）同样没有实测。
- **真实的 Bing / DuckDuckGo 质量不稳**（服务端子任务实测）：Bing 对程序的请求有时给不相关的结果，DuckDuckGo 连发几次
  就限流、国内不挂代理连不上。有词面相关性检查和冷却，但挡不住「词对上了却不是要的那页」。要稳就在设置里填 Tavily /
  Brave 的密钥。
- macOS / Linux 的图标栏和标题栏规则（红绿灯让位）只按数字改了，没在真机上看过。
- 手机上的分区（抽屉里的「扩展」、页面的 tab）只在窄窗口里看过。
- 桌面壳的两处新代码——网页的新窗口变成浏览器标签（`desktop:browserPopup`）、截图的 IPC——前者没有自动检查，后者
  的函数在浏览器冒烟里直接调用过，但没有经过打包后的应用。
